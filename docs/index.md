# Origemite Archive

:::info[노션에서 옮겨 온 글을 다듬고 있습니다]

기존 노션 자료를 AI로 일괄 이전하는 과정에서 일부 글의 문장이나 구성이 어색할 수 있습니다.<br />
이전한 글은 제가 하나씩 읽어 보며 표현을 다듬고, 설명이 부족한 곳에는 코드와 예제를 보강하고 있습니다.

:::

## 제가 개발하면서 남긴 기록입니다

같은 문제를 다시 만났을 때, 예전에 어떤 방법을 시도했고 왜 그쪽을 골랐는지 찾아보고 싶었습니다.<br />
흩어져 있던 개발 메모와 작은 실험, 프로젝트에서 쓴 코드를 한곳에 모으기 시작한 이유입니다.

Java와 Spring으로 백엔드를 만들며 배운 것부터 데이터베이스를 설계하고 서버를 배포하면서 겪은 일까지 적고 있습니다.<br />
기술을 처음 붙여 본 기록도 있고, 실제 프로젝트에서 문제가 생겨 설계를 다시 바꾼 이야기도 있습니다.<br />
시간이 지나 다시 읽었을 때 당시의 조건과 판단을 함께 떠올릴 수 있도록, 어디까지 해봤는지와 무엇이 남았는지도 적어 두려 합니다.

여러 프로젝트에서 반복해서 쓰게 된 코드 구조와 테스트는 **원셋**으로 묶어 두었습니다.<br />
요청을 어디에서 받고 업무 판단은 어디에서 하는지, 바뀐 동작을 어떤 테스트로 확인할지 다음 프로젝트에서도 참고할 수 있게 만든 예제입니다.<br />
AI와 함께 작업할 때 이 구조와 검증 기준을 어떻게 전달하는지도 하네스에 기록합니다.
