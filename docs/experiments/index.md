# Experiments

:::note[작게 시험해 본 기록]

각 글에 해본 것과 확인한 결과를 남깁니다.<br />
프로젝트에 적용할 때 확인할 조건이 남아 있다면 함께 적어 둡니다.

:::

새로운 도구를 써보고 싶을 때는 작은 예제부터 만들어 봅니다.<br />
기동이 되는지, 한 기능이 기대한 대로 동작하는지 확인하면 다음에 어디까지 맡길지 판단하기 쉬워집니다.

실험에서 알아낸 사용법은 [기술 노트](/docs/knowledge/)에 연결합니다.<br />
프로젝트에 도입하기로 했다면 선택 이유를 [설계와 결정](/docs/decisions/)에 남기고, 반복해서 쓰게 된 예제는 [하네스의 템플릿](/docs/harness/templates/)으로 정리합니다.
