# Folder skeleton

> **개요:** 새 FE 앱 또는 도메인 추가 시 빈 트리 안내입니다.
> ExampleItem 저장소: `nutech/fe-v1`.

## 슬롯

| 슬롯 | 요구 |
|------|------|
| api | 도메인 HTTP 모듈 자리 |
| hooks | 조회와 mutation 훅 |
| stores | UI 상태 |
| pages | 유스케이스 조립 |
| templates | 레이아웃과 라우트 |

| 역할 | 경로 |
