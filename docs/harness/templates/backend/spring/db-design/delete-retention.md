# 삭제와 보관

> **필수 경계:** 일반 업무 데이터는 물리 삭제 없이 `status` 등으로 논리 삭제합니다.
> **기본 관례:** 이력·로그·통계 보관은 5년, Outbox 등 이벤트성은 3년 또는 더 짧게 둡니다.
> **기본 관례:** 보관 기간 이후에는 백업·아카이빙 후 운영 데이터를 정리합니다.

| 구분 | 기본 정책 | 강도 |
|------|-----------|------|
| 일반 업무 데이터 | 물리 삭제 없음, `status` `A`/`D` 등 | 필수 경계 |
| 일반 이력·로그·통계 | 기본 5년 보관 | 기본 관례 |
| Outbox 등 이벤트성 | 기본 3년, 용도에 따라 더 짧게 | 상황별 선택 |
| 보관 기간 이후 | 백업·아카이빙 후 정리 | 기본 관례 |

업무 데이터의 논리 삭제와, 파티션 단위 아카이빙은 별도 정책으로 관리합니다.
백업 이후 운영 데이터 정리 절차의 세부 런북은 [후속 작업](./follow-ups)에서 보완합니다.
