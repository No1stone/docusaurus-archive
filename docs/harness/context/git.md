# Git

> **개요:** 커밋은 사용자가 이 작업에서 승인했을 때만 합니다.
> 작성자 정보를 추측하거나 전역 설정을 바꾸지 않습니다.

커밋은 저장소에 적용된 `user.name`, `user.email`로 만듭니다.
없거나 사용자 의도와 다르면 확인을 요청합니다.
이름과 이메일을 추측하지 않습니다.
전역 Git 설정을 바꾸지 않습니다.
별도 요청 없이 AI 공동 작성자 표기를 넣지 않습니다.
사용자의 서명 설정은 유지합니다.

일반 개발 요청만으로 커밋하지 않습니다.
해당 작업에서 커밋이 승인된 경우에만, 검증 뒤에 커밋합니다.
이미 승인된 정책은 다시 묻지 않습니다.

커밋 전에 현재 브랜치, 기존 변경, 이번 범위, 검증 결과, 비밀정보와 생성 파일을 확인합니다.
이번 작업의 변경만 스테이징합니다.
사용자가 작업 중이던 변경을 포함하거나 되돌리지 않습니다.
같은 파일에 섞여 구분할 수 없으면 확인을 요청합니다.

커밋 메시지는 저장소의 기존 규칙을 따릅니다.
규칙이 없으면 무엇이 바뀌었는지 짧게 적습니다.

커밋 뒤에 해시, 작성자, 포함된 변경을 확인합니다.
자기 커밋 해시를 적으려고 커밋을 다시 고치지 않습니다.

push, amend, rebase, 강제 push는 커밋과 별개입니다.
각각 사용자의 요청이나 이미 승인된 정책이 있을 때만 합니다.
