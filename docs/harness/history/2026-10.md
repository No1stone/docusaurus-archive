## 2026-10-23 / 작업 범위 경량화 원칙 반영

- 변경: `workflows/implement.md`를 요청 모드·단일 에이전트·검증·보고 허브로 보강했습니다. orchestration·진입점·Master·Implementer·acceptance·tools·engineering-principles·CURRENT는 참조로 연결했습니다. Knowledge·템플릿 본문과 저장소별 패턴은 유지했습니다.
- 이유: 질문·문서 요청에도 역할 파이프라인이 돌거나, 검증 생략이 통과처럼 보이거나, 재읽기·부하 검증이 과도해지는 것을 줄입니다.
- 검증: 문서 링크 대조. `npm run build` (이 항목 작성 시점 이후 실행). 에이전트 동작 실실행은 없음(규칙 검토).
- 남은 사항: 없음.
- 참조: `docs/harness/workflows/implement.md`, `docs/harness/CURRENT.md`

## 2026-10-14 / 하네스 기본 경로 정리

- 변경: 기본 흐름을 요청, 범위, 템플릿, 통과 기준, 구현, 검증, 짧은 기록으로 통일했습니다. 모든 역할을 매번 실행하지 않습니다. Curator는 사용자 요청 시에만 사용합니다. 구현 우선순위를 프로젝트 규칙, 템플릿, 기존 패턴, 최소 구현으로 고정했습니다.
- 이유: 기존 규칙은 역할 전부를 순서대로 실행하고, 레시피가 없으면 새 파일을 만들게 했습니다. 익숙한 작업에서는 탐색과 반복 판단이 길었습니다.
- 검증: `npm run build` 통과. htdemo 테스트는 실행하지 않음.
- 남은 사항: Facade와 Service 설계 문서의 채택은 사용자 판단입니다. 이번 정리에서 그 본문을 개정하지 않았습니다.
- 참조: `AGENTS.md`, `docs/harness/workflows/implement.md`, `docs/harness/CURRENT.md`

## 2026-10-14 / 레시피와 역할 조건 맞춤

- 변경: `spring-api-one-set`에서 Reviewer와 QA는 책임만 항상 있고, 별도 에이전트는 추가 절차일 때만 실행합니다. 반복 버그는 Curator를 실행하지 않고 후보만 기록합니다. 기본 경로의 Implementer는 테스트 작성과 실행, 자체 검증을 할 수 있습니다. Facade와 Service 문서는 현재 기준으로 맞췄습니다. 리팩터는 기존 테스트 유지와 통과를 기준으로 하고, 필요한 추가는 허용합니다. Spring profile의 Service TODO는 Facade, Service, 테스트 문서 링크로 바꿨습니다.
- 이유: 설명과 표, 문서 상태, 워크플로가 서로 달랐습니다.
- 검증: 문서 대조. 사이트 빌드와 htdemo 테스트는 실행하지 않음.
- 남은 사항: 없음.
- 참조: `docs/harness/orchestrations/spring-api-one-set.md`, `docs/harness/workflows/bugfix.md`, `docs/harness/agents/implementer.md`, `docs/harness/CURRENT.md`

## 2026-10-14 / 기본 흐름과 역할 표 일치

- 변경: 기본 흐름을 범위와 통과 기준, 규칙 및 템플릿, 구현과 테스트, 검증, 짧은 기록, 승인된 경우 커밋으로 맞췄습니다. 별도 에이전트 조건은 implement.md 한 곳입니다. 통과 기준과 테스트 선작성을 나눴습니다. 반복 발견은 후보만 보고합니다. 리팩터는 기존 검증 범위와 동작 유지를 기준으로 합니다. Facade, Service는 구현 기준 채택 전으로 참조를 맞췄습니다.
- 이유: 설명은 조건부인데 역할 표는 Reviewer, QA, Tester를 필수로 두었고, 모든 작업에 테스트 선작성을 요구했습니다.
- 검증: `npm run build` 통과. 앱 테스트는 실행하지 않음.
- 남은 사항: Facade, Service 설계 문서를 구현 기준으로 채택할지는 사용자 판단입니다.
- 참조: `docs/harness/workflows/implement.md`, `docs/harness/workflows/acceptance.md`, `docs/harness/CURRENT.md`
