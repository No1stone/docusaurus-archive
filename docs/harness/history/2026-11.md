## 2026-11-18 / Nginx 네트워크 글 38편과 메뉴

- 프록시, Nginx 기초, 요청 경로, 연결, 스트리밍, Stream, HTTPS, 캐시, 로그의 9개 묶음에 38편을 작성했습니다. 기존 메모는 URL을 유지하며 목차에서 연결했습니다.
- Stream 글에 infra-dev의 MySQL, Redis, RabbitMQ AMQP와 관리 화면 연결 사례를 달았습니다.
- Docusaurus Mermaid 테마를 추가했습니다. 정적 빌드와 브라우저의 사이드바 및 다이어그램 렌더링을 확인했습니다.
- 임시 Nginx 1.30.6 Compose에서 경로 치환, location 매칭, rewrite, 헤더 보정, 두 업스트림 분산, keepalive 설정, DNS 설정, 캐시 HIT와 인증 우회, JSON 로그, 연결 거절 502를 확인했습니다. TLS 인증서와 실제 WebSocket, SSE, DB 및 AMQP 프로토콜을 포함한 종단 간 검증은 수행하지 않았습니다.
- 사이트 빌드는 통과했습니다. 기존 문서의 링크 경고와 Tools의 js-yaml 기본 export 경고가 남아 있습니다.

## 2026-11-19 / Spring 미작성 본문 53편 작성

- 기존 목차와 URL을 유지하며 Core 9편, Boot 6편, 설정 6편, Web 8편, 데이터 접근 8편, 트랜잭션 4편, 비동기와 스케줄링 3편, Batch 4편, 테스트 4편, 구성과 흐름 1편을 작성했습니다. 9개 하위 목차와 Spring 입구에 읽는 순서 및 버전 기준을 연결했습니다.
- 개념, 동작, 예제, 실패 조건과 검증 방법을 설명하고 Mermaid 22개를 추가했습니다. Legacy의 설정 import 캡처를 재사용하고 DI, 생명주기, 동적 스케줄, 다중 DataSource와 Auditing 메모를 현재 설명과 연결했습니다. 기존 Legacy 본문과 URL은 이번 작업에서 변경하지 않았습니다.
- 기준은 Boot 3.5, Framework 6.2, Batch 5.2입니다. 가상 스레드의 Java 21 이상 조건, Jakarta 전환과 프록시 자기 호출의 한계, 설정 초기화 및 실제 보안 버전의 구분을 명시했습니다.
- 임시 환경에서 실제 본문의 DI, 조건부 빈, 설정 바인딩, Async와 RestClient 예제를 추출해 컴파일하고, H2에서 롤백과 자기 호출 및 REQUIRES_NEW를 확인했습니다. 12개 확인을 통과했습니다. 모든 코드 조각의 독립 컴파일이나 MySQL, PostgreSQL, 실제 외부 서비스 및 부하 검증을 수행한 것은 아닙니다.
- 본문 내부 상대 링크와 이미지 경로, 코드 펜스 및 미작성 표시 잔여를 점검했습니다. 공식 링크 77개 중 404 한 개를 올바른 ItemReader와 ItemStream 링크로 교체했습니다.
- 전체 사이트 빌드는 별도 출력 경로에서 통과했습니다. 기존 문서 링크, js-yaml export와 Spring Core 리다이렉트 충돌 경고는 이번 범위 밖으로 남겼습니다.
- 최종 빌드를 다시 통과했고, DOM 환경에서 Mermaid 22개 모두 문법 검사를 통과했습니다. 주요 코드 확인은 Boot 3.5.16과 Framework 6.2.19, H2 2.3.232로 수행했습니다.
