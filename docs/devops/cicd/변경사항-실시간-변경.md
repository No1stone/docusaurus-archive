# 변경사항 실시간 변경

> **개요:** 코드나 이미지 변경을 컨테이너에 바로 반영할 때 쓰는 docker-compose 명령 메모입니다.

## 명령

```bash
docker-compose up --build --force-recreate -d
```

`--build`로 이미지를 다시 만들고, `--force-recreate`로 컨테이너를 재생성한 뒤, `-d`로 백그라운드 실행합니다.
compose 파일이 있는 디렉터리에서 실행합니다.
