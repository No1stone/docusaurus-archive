# AI 개발 아키텍처

AI와 개발할 때는 제품이 보장할 동작과 프로젝트에서 사용하는 구현 방식을 각각 둡니다.<br />
제품 명세에는 기대 동작과 통과 기준을 둡니다.<br />
구현 원셋에는 새 기능을 만들 때 재사용할 코드 구조와 테스트 예제를 둡니다.

- [Template-Driven Development](/docs/architecture/ai-development/template-driven-development)에서 검증된 구현과 테스트를 한 벌로 재사용하는 방식을 설명합니다.
- [Specification-Driven Development](/docs/architecture/ai-development/specification-driven-development)에서 제품 동작을 명세로 정하고 변경을 검증하는 방식을 설명합니다.
