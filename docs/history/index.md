# History

:::note[개발 방식이 바뀐 과정을 기록합니다]

지금 쓰는 구조가 어디에서 출발했는지 궁금할 때 읽는 페이지입니다.<br />
하네스를 수정하며 남긴 작업 기록은 [하네스 작업 히스토리](/docs/harness/history/)에서 볼 수 있습니다.

:::

처음에는 손으로 맞추던 구조도 여러 번 쓰다 보면 어느 부분을 고정하고 어느 부분을 바꿔야 할지 보입니다.<br />
이곳에는 그런 기준이 생긴 계기와, 다른 방식을 시험한 뒤 무엇을 가져왔는지 남깁니다.

> 기존 구현 → 겪은 문제 → 작은 실험 → 설계 결정 → 현재 원셋

특정 결정을 확인하려면 [ADR](/docs/decisions/)에서, 다음 프로젝트에 적용할 코드가 필요하다면 [하네스의 템플릿](/docs/harness/templates/)에서 시작할 수 있습니다.
