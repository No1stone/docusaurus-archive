# History

> **개요:** 엔지니어링 방식이 어떻게 바뀌어 왔는지. Changelog가 아니며 기본 컨텍스트가 아님.

Not a changelog. Tracks how the engineering approach evolved:

```text
Old implementation → Problem → Experiment → ADR → New implementation → Current template
```

Coding agents should not load History by default. Use it when the *why* behind the current approach matters.
