# Browser guid

## 개요

브라우저 정보로 GUID를 만드는 JavaScript 접근을 담은 블로그 링크입니다.

> 원본 링크 제목은 “Using JavaScript to create a GUID from a user’s browser information”입니다.
클라이언트에서 비교적 안정적인 식별자를 만들 때, 브라우저 환경 값을 조합해 GUID 형태를 만드는 아이디어를 참고하려고 저장했습니다.
서버 발급 UUID나 쿠키 기반 식별자와는 목적과 충돌 가능성이 다르므로, 원문 맥락을 확인한 뒤 적용합니다.
작성 시점에 ` 본문 조회가 실패했습니다(HTTP 404).
링크는 유지하며, 아카이브나 다른 미러가 있으면 그쪽을 확인합니다.
브라우저 fingerprint 계열 기법은 개인정보와 정확도 이슈가 있으므로, 구현 전에 원문과 최신 브라우저 정책을 함께 봅니다.
