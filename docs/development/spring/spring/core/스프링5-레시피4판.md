# 스프링5 레시피4판

## 개요

스프링5 레시피 4판을 보며 남긴 학습 허브입니다.
IoC·POJO 용어와 Core, MVC, Rest 절로 이어집니다.

## 용어

- IoC: Inversion of Control (제어의 역전)
- POJO: Plain Old Java Object
- CSV: comma-separated values (`value, value`)

현재 프로젝트는 Boot 3 / Framework 6 계열이어도, 책의 IoC·빈 생명주기·MVC 요청 흐름 개념은 그대로 도움이 됩니다.
