# Security

인증, 인가, 시크릿, 암호처럼 보안이 주된 목적인 글의 입구입니다.
Gateway에서의 권한 라우팅 패턴은 [Patterns](/docs/patterns/architecture-patterns/gateway-authorization-routing)를 봅니다.
서비스 약관·동의와 공급망을 함께 볼 때는 [개발과 운영 정책](/docs/knowledge/dev-ops-policies)을 봅니다.
