# RedisPubSub

## 개요

Redis Pub/Sub을 다룰 때 남긴 짧은 메모입니다.
발행(Pub)과 구독(Subscriber) 역할을 구분합니다.

## 구성

레디스 퍼브서브입니다.

- Subscriber: 채널을 구독하고 메시지를 받습니다.
- Pub: 채널에 메시지를 발행합니다.
