# RedisPubSub

> **개요:** 발행과 구독 역할만 남긴 짧은 메모입니다.
> 예제와 작업 큐와의 구분은 [Pub/Sub](/docs/knowledge/k-pubsub)을 봅니다.

- Subscriber: 채널을 구독하고 메시지를 받습니다.
- Publisher: 채널에 메시지를 발행합니다.
