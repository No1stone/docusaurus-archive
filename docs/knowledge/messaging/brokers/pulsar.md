# Pulsar

## 개요

Apache Pulsar LTS(3.0.0) 릴리스와 학습 메모입니다. 작성일 2024.04.05.

Apache Pulsar를 공부하기 위해 남긴 메모입니다.
작성일은 2024.04.05입니다.
첫 LTS 릴리스를 계기로 학습 가치가 있다고 판단한 기록입니다.
Pulsar는 2023년 5월 3일, 3.0.0을 기준으로 첫 LTS 버전이 릴리즈되었습니다.
LTS가 있다는 것은 공부해 볼 가치가 생겼다고 생각해 준비를 시작했습니다.
Pulsar는 18개월 단위로 LTS를 준비한다고 합니다.
