# Responsive

> **개요:** 관리 콘솔도 좁은 폭에서 핵심 조작이 가능해야 합니다.

## 계약

1. 필터 패널은 좁은 폭에서 세로 스택 또는 스크롤로 필드가 잘리지 않게 합니다.
2. 표는 가로 스크롤을 허용하되, 주요 액션(조회, 등록)은 뷰포트 안에 둡니다.
3. Sheet와 Dialog는 모바일 폭에서 전체 또는 거의 전체 높이를 쓸 수 있어야 합니다.
4. 사이드바는 접기 또는 오버레이 패턴을 유지합니다 (fe-v1 AdminLayout).

## 검수

- [ ] 1280px와 768px 이하에서 필터 조회가 가능
- [ ] 목록 행 클릭 후 상세 시트가 열림
- [ ] 다크와 함께 깨짐 없음
