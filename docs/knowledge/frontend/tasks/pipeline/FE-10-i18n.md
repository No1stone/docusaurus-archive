# FE-10 — i18n (도메인 네임스페이스)

> **선행:** FE-04 이상 (화면 문구 확정 후) · **다음:** [QA-after-FE-10-i18n](./qa/QA-after-FE-10-i18n.md)  
> **레퍼런스:** `deviceProduction` 키 — `fe-v1/src/i18n/locales/ko.json`, `en.json`

## 이 태스크에서 할 것

- [ ] 네임스페이스 `{camelDomain}` 추가 (예: `deviceProduction`, `farmLivestock`)
- [ ] **하드코드 한글/영문 제거** — `t("{ns}.…")` 로 통일
- [ ] 필수 로케일: **`ko`**, **`en`**
- [ ] 권장: `ja`, `es`, `ru` 동일 키 (없으면 en fallback 확인)

## 최소 키 세트 (CRUD 1세트)

| 키 | 용도 |
|----|------|
| `statusAll`, `statusA`, `statusD` | 필터·Badge (`A`/`D` 문자열 UI 금지) |
| `deactivate` | 비활성 버튼 |
| `deactivateSuccess`, `deactivateFailed` | 토스트 |
| `loadFailed` | 목록 실패 |
| `formSaveCreateSuccess`, `formSaveEditSuccess`, `formSaveFailed` | FormSheet |
| `downloadTitle`, `downloadFilename`, … | DownloadModal (FE-08 시) |
| 목록 컬럼 | `col*` 또는 `list.*` |
| 필터 라벨 | `keywordPlaceholder`, 필드명 |

공통 오딧 라벨은 **`common.jpaAudit.*`** 재사용 — 도메인에 중복 정의 금지.
