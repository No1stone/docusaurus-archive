# 오버레이와 보조 화면

모달, 드로어, 바텀 시트, 툴팁 등 오버레이 UI 요소 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [모달 (Modal)](/docs/knowledge/frontend/ui-ux-elements/modal) | `Modal` | 중앙 모달을 열고 Esc/바깥 클릭/버튼으로 닫습니다. 닫으면 열기 버튼으로 포커스가 돌아옵니다. 드로어·바텀 시트와 위치를 비교하세요. 하단 시트는 [바텀 시트](/docs/knowledge/frontend/ui-ux-elements/bottom-sheet), 측면은 [드로어](/docs/knowledge/frontend/ui-ux-elements/drawer)를 봅니다. |
| [확인 다이얼로그 (Confirm Dialog)](/docs/knowledge/frontend/ui-ux-elements/confirm-dialog) | `Confirm Dialog` | 삭제 확인에서 취소와 확인을 각각 눌러 봅니다. 일반 모달보다 결정 동작에 초점을 둡니다. |
| [드로어 (Drawer)](/docs/knowledge/frontend/ui-ux-elements/drawer) | `Drawer` | 옆에서 열리는 패널입니다. 모달(중앙)·바텀 시트(하단)와 비교하세요. 중앙은 [모달](/docs/knowledge/frontend/ui-ux-elements/modal), 하단은 [바텀 시트](/docs/knowledge/frontend/ui-ux-elements/bottom-sheet)를 봅니다. |
| [바텀 시트 (Bottom Sheet)](/docs/knowledge/frontend/ui-ux-elements/bottom-sheet) | `Bottom Sheet` | 아래에서 올라오는 시트입니다. 모달·드로어와 비교하세요. 중앙은 [모달](/docs/knowledge/frontend/ui-ux-elements/modal), 측면은 [드로어](/docs/knowledge/frontend/ui-ux-elements/drawer)를 봅니다. |
| [툴팁 (Tooltip)](/docs/knowledge/frontend/ui-ux-elements/tooltip) | `Tooltip` | 호버/포커스로 짧은 설명을 띄웁니다. 팝오버보다 단순합니다. |
| [팝오버 (Popover)](/docs/knowledge/frontend/ui-ux-elements/popover) | `Popover` | 앵커 옆 패널에서 부가 정보를 봅니다. 툴팁보다 내용이 깁니다. |
| [드롭다운 메뉴 (Dropdown Menu)](/docs/knowledge/frontend/ui-ux-elements/dropdown-menu) | `Dropdown Menu` | 트리거로 메뉴를 열어 항목을 고릅니다. |
| [컨텍스트 메뉴 (Context Menu)](/docs/knowledge/frontend/ui-ux-elements/context-menu) | `Context Menu` | 우클릭 또는 대체 버튼으로 메뉴를 엽니다. |
| [라이트박스 (Lightbox)](/docs/knowledge/frontend/ui-ux-elements/fullscreen-preview) | `Lightbox` | 미리보기를 전체 화면으로 열고 닫습니다. |
