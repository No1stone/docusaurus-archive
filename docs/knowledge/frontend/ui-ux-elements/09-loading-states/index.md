# 로딩과 화면 상태

스피너, 스켈레톤, 프로그레스 바, 빈 상태, 오류·재시도 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [버튼 로딩 (Button Loading)](/docs/knowledge/frontend/ui-ux-elements/button-pending) | `Button Loading` | 저장을 눌러 대기 잠금을 확인합니다. |
| [스피너 (Spinner)](/docs/knowledge/frontend/ui-ux-elements/spinner) | `Spinner` | 짧은 대기 스피너를 켭니다. |
| [스켈레톤 (Skeleton)](/docs/knowledge/frontend/ui-ux-elements/skeleton) | `Skeleton` | 콘텐츠 모양 스켈레톤을 확인합니다. |
| [프로그레스 바 (Progress Bar)](/docs/knowledge/frontend/ui-ux-elements/progress) | `Progress Bar` | 진행 바 값이 갱신되는지 확인합니다. 업로드 흐름의 프로그레스 바는 파일 카테고리도 봅니다. 업로드 맥락은 [업로드 프로그레스](/docs/knowledge/frontend/ui-ux-elements/upload-progress)를 봅니다. |
| [빈 상태 (Empty State)](/docs/knowledge/frontend/ui-ux-elements/empty-first) | `Empty State` | 첫 방문 빈 상태 안내와 시작 동작을 확인합니다. |
| [검색 결과 없음 (No Results)](/docs/knowledge/frontend/ui-ux-elements/empty-search) | `No Results` | 결과 없음 안내를 확인합니다. |
| [부분 로딩·실패 (Partial State)](/docs/knowledge/frontend/ui-ux-elements/partial-state) | `Partial Loading / Failure` | 구역마다 다른 상태를 확인합니다. |
| [오류·재시도 (Error & Retry)](/docs/knowledge/frontend/ui-ux-elements/error-retry) | `Error & Retry` | 실패 후 재시도로 복구합니다. |
| [오프라인 배너 (Offline Banner)](/docs/knowledge/frontend/ui-ux-elements/offline) | `Offline Banner` | 오프라인/재연결 안내를 전환합니다. |
| [권한 없음 (Forbidden)](/docs/knowledge/frontend/ui-ux-elements/forbidden) | `Forbidden / 403` | 권한 없음 안내를 확인합니다. |
