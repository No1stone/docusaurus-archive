# 정보 표시

카드, 배지, 칩, 태그, 타임라인 등 정보 표시 UI 요소 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [카드 (Card)](/docs/knowledge/frontend/ui-ux-elements/card) | `Card` | 카드 제목, 본문, 동작을 확인합니다. |
| [리스트 (List)](/docs/knowledge/frontend/ui-ux-elements/list) | `List` | 행을 선택해 강조 상태를 확인합니다. |
| [배지 (Badge)](/docs/knowledge/frontend/ui-ux-elements/badge) | `Badge` | 상태·수치를 표시하는 읽기 전용 배지입니다. 선택형 칩·알림 배지와 구분합니다. 알림 숫자는 [알림 배지](/docs/knowledge/frontend/ui-ux-elements/notification-badge)를 봅니다. |
| [칩 (Chip)](/docs/knowledge/frontend/ui-ux-elements/chip) | `Chip` | 눌러 선택하거나 제거할 수 있는 칩입니다. 배지(읽기 전용)·태그(분류 라벨)와 다릅니다. 필터 칩은 검색 카테고리를 봅니다. 필터 칩은 [필터 칩](/docs/knowledge/frontend/ui-ux-elements/filter-chips)을 봅니다. |
| [태그 (Tag)](/docs/knowledge/frontend/ui-ux-elements/tag) | `Tag` | 읽기 전용 분류 라벨입니다. 칩처럼 선택하지 않습니다. |
| [아바타 (Avatar)](/docs/knowledge/frontend/ui-ux-elements/avatar) | `Avatar` | 이니셜/폴백과 겹치는 아바타 그룹을 확인합니다. |
| [구분선 (Divider)](/docs/knowledge/frontend/ui-ux-elements/divider) | `Divider` | 구역을 나누는 선과 여백을 확인합니다. |
| [설명 목록 (Description List)](/docs/knowledge/frontend/ui-ux-elements/description-list) | `Description List` | 라벨-값 쌍 정렬을 확인합니다. |
| [타임라인 (Timeline)](/docs/knowledge/frontend/ui-ux-elements/timeline) | `Timeline` | 이벤트를 시간 순으로 스크롤합니다. |
| [디스클로저 (Disclosure)](/docs/knowledge/frontend/ui-ux-elements/expand-detail) | `Disclosure` | 요약/상세를 접고 펼칩니다. details/summary 패턴입니다. |
| [수치 카드 (Stat Card)](/docs/knowledge/frontend/ui-ux-elements/stat-card) | `Stat Card` | 핵심 숫자와 증감 표시를 확인합니다. |
| [차트·범례 (Chart & Legend)](/docs/knowledge/frontend/ui-ux-elements/chart-legend) | `Chart Legend` | 범례를 눌러 시리즈를 숨기고 켭니다. |
