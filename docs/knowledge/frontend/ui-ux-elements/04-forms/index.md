# 폼과 검증

필수 표시, 인라인 검증, 오류 요약, 멀티스텝 폼 등 폼 패턴 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [필수 표시 (Required Indicator)](/docs/knowledge/frontend/ui-ux-elements/required-hint) | `Required Indicator` | 필수 표시(*)와 제출 전 안내를 확인합니다. |
| [인라인 검증 (Inline Validation)](/docs/knowledge/frontend/ui-ux-elements/inline-validation) | `Inline Validation` | 잘못된 값 아래 필드 오류가 뜨는지 확인합니다. |
| [오류 요약 (Error Summary)](/docs/knowledge/frontend/ui-ux-elements/error-summary) | `Error Summary` | 제출 실패 시 요약에서 첫 오류 필드로 이동합니다. |
| [비밀번호 필드 (Password Field)](/docs/knowledge/frontend/ui-ux-elements/password-reveal) | `Password Field` | 보기 아이콘으로 가리기/표시를 전환합니다. |
| [OTP 입력 (OTP Input)](/docs/knowledge/frontend/ui-ux-elements/otp-input) | `OTP Input` | 칸 단위 입력과 자동 이동을 확인합니다. |
| [동적 폼 행 (Dynamic Form Rows)](/docs/knowledge/frontend/ui-ux-elements/dynamic-rows) | `Dynamic Form Rows` | 행을 추가/삭제한 뒤 값이 유지되는지 확인합니다. |
| [멀티스텝 폼 (Multi-step Form)](/docs/knowledge/frontend/ui-ux-elements/multi-step-form) | `Multi-step Form` | 단계 이동 시 이전 값이 보존되는지 확인합니다. |
| [저장 피드백 (Save Feedback)](/docs/knowledge/frontend/ui-ux-elements/save-result) | `Save Feedback` | 클릭→눌림→처리 중→성공/실패를 재현합니다. |
| [이탈 확인 (Unsaved Changes)](/docs/knowledge/frontend/ui-ux-elements/unsaved-leave) | `Unsaved Changes Guard` | 값을 바꾼 뒤 나가기에서 확인 대화를 받습니다. |
