# 파일과 미디어

파일 피커, 드롭존, 프로그레스 바, 갤러리, 캐러셀 미디어 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [파일 피커·드롭존 (File Picker & Drop Zone)](/docs/knowledge/frontend/ui-ux-elements/file-drop) | `File Picker & Drop Zone` | 파일 선택과 드래그 앤 드롭으로 파일을 고릅니다. 업로드 진행은 프로그레스 바 데모를 봅니다. 진행률은 [업로드 프로그레스](/docs/knowledge/frontend/ui-ux-elements/upload-progress)를 봅니다. |
| [파일 검증 (File Validation)](/docs/knowledge/frontend/ui-ux-elements/file-validation) | `File Validation` | 허용되지 않은 형식·용량에서 오류를 확인합니다. |
| [업로드 프로그레스 (Upload Progress)](/docs/knowledge/frontend/ui-ux-elements/upload-progress) | `Upload Progress` | 프로그레스 바가 갱신되며 취소·실패·재시도를 재현합니다. 단독 프로그레스 바는 로딩 카테고리도 봅니다. 단독 프로그레스 바는 [프로그레스 바](/docs/knowledge/frontend/ui-ux-elements/progress)를 봅니다. |
| [첨부 목록 (Attachment List)](/docs/knowledge/frontend/ui-ux-elements/attachment-list) | `Attachment List` | 첨부 다운로드를 실행합니다. |
| [이미지 줌 (Image Zoom)](/docs/knowledge/frontend/ui-ux-elements/image-zoom) | `Image Zoom` | 미리보기를 열고 확대합니다. |
| [갤러리 (Gallery)](/docs/knowledge/frontend/ui-ux-elements/gallery) | `Gallery` | 썸네일 그리드에서 이미지를 고릅니다. |
| [캐러셀 (Carousel)](/docs/knowledge/frontend/ui-ux-elements/carousel) | `Carousel` | 좌우로 이미지를 넘깁니다. |
