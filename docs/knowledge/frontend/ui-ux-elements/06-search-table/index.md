# 검색, 필터, 데이터 테이블

목록 검색, 필터 칩, 정렬, 테이블 헤더 고정 등 목록·테이블 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [목록 검색 (List Search)](/docs/knowledge/frontend/ui-ux-elements/list-search) | `List Search` | 검색 입력에 따라 목록이 즉시 갱신됩니다. 자동완성과 달리 결과 목록 필터에 초점을 둡니다. 자동완성은 [자동완성](/docs/knowledge/frontend/ui-ux-elements/autocomplete)을 봅니다. |
| [필터 칩 (Filter Chips)](/docs/knowledge/frontend/ui-ux-elements/filter-chips) | `Filter Chips` | 칩으로 목록을 좁히고 한 번에 초기화합니다. 일반 칩은 [칩](/docs/knowledge/frontend/ui-ux-elements/chip)을 봅니다. |
| [정렬 (Sort)](/docs/knowledge/frontend/ui-ux-elements/sort) | `Sort` | 오름/내림차순을 전환합니다. |
| [무한 스크롤 (Infinite Scroll)](/docs/knowledge/frontend/ui-ux-elements/infinite-scroll) | `Infinite Scroll` | 끝으로 스크롤하면 다음 묶음이 모의 로딩됩니다. |
| [일괄 작업 (Bulk Actions)](/docs/knowledge/frontend/ui-ux-elements/bulk-actions) | `Bulk Actions` | 여러 행을 고른 뒤 일괄 동작을 실행합니다. |
| [고정 테이블 헤더 (Sticky Table Header)](/docs/knowledge/frontend/ui-ux-elements/sticky-table) | `Sticky Table Header` | 스크롤해도 헤더·첫 열이 남는지 확인합니다. 페이지 스티키 헤더는 [스티키 헤더](/docs/knowledge/frontend/ui-ux-elements/sticky-header)를 봅니다. |
| [열 설정 (Column Config)](/docs/knowledge/frontend/ui-ux-elements/column-config) | `Column Config` | 열을 숨기고 순서를 바꿉니다. |
| [행 확장 (Expandable Row)](/docs/knowledge/frontend/ui-ux-elements/row-expand) | `Expandable Row` | 행을 펼쳐 상세를 확인합니다. |
| [인라인 편집 (Inline Edit)](/docs/knowledge/frontend/ui-ux-elements/inline-edit) | `Inline Edit` | 셀을 고쳐 값이 반영되는지 확인합니다. |
| [반응형 테이블 (Responsive Table)](/docs/knowledge/frontend/ui-ux-elements/narrow-table) | `Responsive Table` | 폭을 줄여 카드형 대체 보기를 확인합니다. |
