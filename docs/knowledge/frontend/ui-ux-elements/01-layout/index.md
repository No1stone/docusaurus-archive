# 화면 골격과 레이아웃

헤더, 사이드바, 분할 패널, 그리드 등 화면 골격 UI 요소 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [헤더 (Header)](/docs/knowledge/frontend/ui-ux-elements/header) | `Header` | 데모 영역 안 상단 헤더의 로고와 동작을 확인합니다. 사이트 전역 헤더와 별개입니다. |
| [스티키 헤더 (Sticky Header)](/docs/knowledge/frontend/ui-ux-elements/sticky-header) | `Sticky Header` | 데모 스크롤 영역 안에서만 헤더가 고정됩니다. 테이블 헤더 고정은 데이터 테이블 데모를 봅니다. 테이블 헤더 고정은 [고정 테이블 헤더](/docs/knowledge/frontend/ui-ux-elements/sticky-table)를 봅니다. |
| [사이드바 (Sidebar)](/docs/knowledge/frontend/ui-ux-elements/sidebar) | `Sidebar` | 접기와 펼치기로 본문 폭 변화를 확인합니다. |
| [푸터 (Footer)](/docs/knowledge/frontend/ui-ux-elements/footer) | `Footer` | 데모 스크롤 끝의 푸터 링크와 여백을 확인합니다. |
| [스티키 액션 바 (Sticky Action Bar)](/docs/knowledge/frontend/ui-ux-elements/sticky-action-bar) | `Sticky Action Bar` | 스크롤해도 하단 저장/취소 바가 영역에 남는지 확인합니다. |
| [단일·다중 열 (Columns)](/docs/knowledge/frontend/ui-ux-elements/columns) | `Columns` | 폭 옵션을 바꿔 한 열과 여러 열 배치를 비교합니다. |
| [분할 패널 (Split Panel)](/docs/knowledge/frontend/ui-ux-elements/split-panel) | `Split Panel` | 가운데 핸들을 드래그해 좌우 비율을 바꿉니다. Resizable panes. |
| [목록·상세 (Master-Detail)](/docs/knowledge/frontend/ui-ux-elements/list-detail) | `Master-Detail` | 목록에서 항목을 고르면 상세 패널이 채워집니다. |
| [반응형 그리드 (Responsive Grid)](/docs/knowledge/frontend/ui-ux-elements/responsive-grid) | `Responsive Grid` | 데모 폭을 줄이며 카드 열이 재배치되는지 확인합니다. |
| [벤토 그리드 (Bento Grid)](/docs/knowledge/frontend/ui-ux-elements/bento-grid) | `Bento Grid` | 크기가 다른 타일 배치를 스크롤하며 확인합니다. |
