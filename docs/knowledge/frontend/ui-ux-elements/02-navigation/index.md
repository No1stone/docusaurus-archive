# 내비게이션

상단·하단 메뉴, 탭, 브레드크럼, 스텝퍼 등 내비게이션 UI 요소 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [상단 메뉴 (Top Navigation)](/docs/knowledge/frontend/ui-ux-elements/top-menu) | `Top Navigation` | 메뉴를 눌러 활성 항목이 바뀌는지 확인합니다. |
| [햄버거 메뉴 (Hamburger Menu)](/docs/knowledge/frontend/ui-ux-elements/hamburger-menu) | `Hamburger Menu` | 햄버거로 오버레이 메뉴를 열고 항목을 고른 뒤 닫습니다. |
| [하단 내비 (Bottom Navigation)](/docs/knowledge/frontend/ui-ux-elements/bottom-nav) | `Bottom Navigation` | 하단 탭을 눌러 화면 라벨이 바뀌는지 확인합니다. |
| [탭 (Tabs)](/docs/knowledge/frontend/ui-ux-elements/tabs) | `Tabs` | 탭을 바꿔 패널 내용만 교체되는지 확인합니다. |
| [브레드크럼 (Breadcrumb)](/docs/knowledge/frontend/ui-ux-elements/breadcrumb) | `Breadcrumb` | 경로 조각을 눌러 상위 위치로 이동합니다. |
| [아코디언 (Accordion)](/docs/knowledge/frontend/ui-ux-elements/accordion-menu) | `Accordion` | 그룹을 펼치고 접어 하위 항목을 드러냅니다. |
| [스텝퍼 (Stepper)](/docs/knowledge/frontend/ui-ux-elements/stepper) | `Stepper` | 다음/이전으로 단계를 이동하고 완료 표시를 확인합니다. |
| [페이지 목차 (Table of Contents)](/docs/knowledge/frontend/ui-ux-elements/page-toc) | `Table of Contents` | 목차 항목을 눌러 데모 안 구역으로 스크롤합니다. |
| [페이지네이션 (Pagination)](/docs/knowledge/frontend/ui-ux-elements/pagination) | `Pagination` | 페이지 번호로 목록 구간을 바꿉니다. 무한 스크롤은 별도 데모입니다. 무한 스크롤은 [무한 스크롤](/docs/knowledge/frontend/ui-ux-elements/infinite-scroll)을 봅니다. |
| [더 보기 (Load More)](/docs/knowledge/frontend/ui-ux-elements/load-more) | `Load More` | 더 보기를 눌러 다음 묶음이 이어 붙는지 확인합니다. |
