# 알림과 피드백

토스트, 스낵바, 배너, 알림 배지 등 피드백 UI 요소 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [토스트 (Toast)](/docs/knowledge/frontend/ui-ux-elements/toast) | `Toast` | 짧은 알림이 나타났다 자동으로 사라집니다. 실행 취소 버튼이 있는 스낵바와 구분합니다. 실행 취소가 있으면 [스낵바](/docs/knowledge/frontend/ui-ux-elements/snackbar-undo)를 봅니다. |
| [스낵바 (Snackbar)](/docs/knowledge/frontend/ui-ux-elements/snackbar-undo) | `Snackbar` | 삭제 후 실행 취소 액션이 있는 스낵바입니다. 토스트(자동 소멸, 액션 없음)와 다릅니다. 액션 없는 알림은 [토스트](/docs/knowledge/frontend/ui-ux-elements/toast)를 봅니다. |
| [인라인 메시지 (Inline Message)](/docs/knowledge/frontend/ui-ux-elements/inline-message) | `Inline Message` | 패널 안 고정 안내 메시지를 확인합니다. |
| [배너 (Banner)](/docs/knowledge/frontend/ui-ux-elements/announcement-banner) | `Banner` | 상단 공지 배너를 닫을 수 있습니다. |
| [복사 피드백 (Copy Feedback)](/docs/knowledge/frontend/ui-ux-elements/copy-feedback) | `Copy Feedback` | 복사 버튼 후 완료 표시를 확인합니다. |
| [알림 배지 (Notification Badge)](/docs/knowledge/frontend/ui-ux-elements/notification-badge) | `Notification Badge` | 아이콘 위 미확인 개수 배지입니다. 일반 상태 배지와 역할이 다릅니다. |
| [알림 센터 (Notification Center)](/docs/knowledge/frontend/ui-ux-elements/notification-center) | `Notification Center` | 알림을 읽으면 미확인 건수가 줄어듭니다. |
