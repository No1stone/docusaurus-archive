# UI/UX 요소

웹과 모바일에서 쓰는 UI 요소를 **메뉴 이름 → 데모 조작 → 같은 이름으로 구현 요청**할 수 있게 모았습니다.
페이지 제목은 `한글 (English)` 형식이며, 사이드바에는 짧은 이름을 둡니다.

## 자주 묻는 질문

### 프로그레스 바는 어디에 있나요?

단독 요소는 [프로그레스 바 (Progress Bar)](/docs/knowledge/frontend/ui-ux-elements/progress)입니다.
업로드 흐름에서 같은 요소를 쓰려면 [업로드 프로그레스](/docs/knowledge/frontend/ui-ux-elements/upload-progress)를 봅니다.

### 배지와 칩·태그는 어떻게 다른가요?

[배지](/docs/knowledge/frontend/ui-ux-elements/badge)는 읽기 전용 상태·수치, [칩](/docs/knowledge/frontend/ui-ux-elements/chip)은 선택·해제, [태그](/docs/knowledge/frontend/ui-ux-elements/tag)는 고정 분류 라벨입니다.

### 모달과 바텀 시트는 어디서 찾나요?

사이드바 **오버레이와 보조 화면**에서 [모달 (Modal)](/docs/knowledge/frontend/ui-ux-elements/modal), [바텀 시트 (Bottom Sheet)](/docs/knowledge/frontend/ui-ux-elements/bottom-sheet), [드로어 (Drawer)](/docs/knowledge/frontend/ui-ux-elements/drawer)를 각각 엽니다.

### Toast와 Snackbar 차이는?

[토스트 (Toast)](/docs/knowledge/frontend/ui-ux-elements/toast)는 자동 소멸, [스낵바 (Snackbar)](/docs/knowledge/frontend/ui-ux-elements/snackbar-undo)는 실행 취소 같은 액션이 있습니다.
