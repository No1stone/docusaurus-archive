# 버튼과 입력 컨트롤

버튼, 토글, 셀렉트, 자동완성, 날짜 피커 등 입력 컨트롤 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [버튼 (Button)](/docs/knowledge/frontend/ui-ux-elements/button) | `Button` | 기본/강조/비활성 버튼을 눌러 상태 차이를 확인합니다. |
| [아이콘 버튼 (Icon Button)](/docs/knowledge/frontend/ui-ux-elements/icon-button) | `Icon Button` | 아이콘 버튼을 눌러 aria-label 안내를 확인합니다. |
| [플로팅 액션 버튼 (FAB)](/docs/knowledge/frontend/ui-ux-elements/fab) | `Floating Action Button` | 스크롤 중 FAB를 눌러 동작이 실행되는지 확인합니다. |
| [버튼 그룹 (Button Group)](/docs/knowledge/frontend/ui-ux-elements/button-group) | `Button Group` | 묶인 버튼 중 하나를 골라 선택 상태를 유지합니다. |
| [세그먼트 컨트롤 (Segmented Control)](/docs/knowledge/frontend/ui-ux-elements/segmented) | `Segmented Control` | 세그먼트를 바꿔 보기 모드가 바뀌는지 확인합니다. |
| [텍스트 필드 (Text Field)](/docs/knowledge/frontend/ui-ux-elements/text-input) | `Text Field` | 한 줄 입력, 지우기, 글자 수 표시를 확인합니다. |
| [텍스트 영역 (Textarea)](/docs/knowledge/frontend/ui-ux-elements/textarea) | `Textarea` | 여러 줄 입력과 높이 변화를 확인합니다. |
| [체크박스 (Checkbox)](/docs/knowledge/frontend/ui-ux-elements/checkbox-select-all) | `Checkbox` | 개별/전체 선택과 중간(indeterminate) 상태를 확인합니다. |
| [라디오 (Radio)](/docs/knowledge/frontend/ui-ux-elements/radio) | `Radio` | 배타적 선택지 중 하나만 고를 수 있는지 확인합니다. |
| [토글 스위치 (Switch)](/docs/knowledge/frontend/ui-ux-elements/toggle) | `Switch` | 스위치를 켜고 끄며 즉시 반영을 확인합니다. |
| [셀렉트 (Select)](/docs/knowledge/frontend/ui-ux-elements/select) | `Select` | 목록에서 항목을 고릅니다. |
| [콤보박스 (Combobox)](/docs/knowledge/frontend/ui-ux-elements/combobox) | `Combobox` | 직접 입력과 목록 선택을 섞어 값을 정합니다. |
| [자동완성 (Autocomplete)](/docs/knowledge/frontend/ui-ux-elements/autocomplete) | `Autocomplete` | 글자를 치며 제안을 고릅니다. 목록 검색 데모는 결과 갱신 흐름을 봅니다. 목록 검색은 [목록 검색](/docs/knowledge/frontend/ui-ux-elements/list-search)을 봅니다. |
| [슬라이더 (Slider)](/docs/knowledge/frontend/ui-ux-elements/slider) | `Slider` | 핸들을 끌어 숫자 값이 바뀌는지 확인합니다. |
| [숫자 입력 (Number Input)](/docs/knowledge/frontend/ui-ux-elements/number-input) | `Number Input` | 스텝 버튼과 직접 입력으로 범위를 지킵니다. |
| [날짜 피커 (Date Picker)](/docs/knowledge/frontend/ui-ux-elements/date-picker) | `Date Picker` | 날짜를 고르고 표시 형식을 확인합니다. |
| [시간 피커 (Time Picker)](/docs/knowledge/frontend/ui-ux-elements/time-picker) | `Time Picker` | 시간을 고르고 값을 확인합니다. |
| [날짜 범위 피커 (Date Range Picker)](/docs/knowledge/frontend/ui-ux-elements/date-range) | `Date Range Picker` | 시작/종료를 고르고 잘못된 범위를 막아 봅니다. |
