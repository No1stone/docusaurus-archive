# 접근성과 화면 설정

키보드 탐색, 포커스, 라이브 리전, 컬러 모드 등 접근성 데모입니다.

상위 모음: [UI/UX 요소](/docs/knowledge/frontend/ui-ux-elements)

메뉴·페이지 제목의 이름을 AI 구현 요청에 그대로 쓸 수 있습니다. 괄호 안은 통용 영문명입니다.

## 데모

| 요소 | 영문 | 해볼 동작 |
|---|---|---|
| [키보드 탐색 (Keyboard Navigation)](/docs/knowledge/frontend/ui-ux-elements/keyboard-nav) | `Keyboard Navigation` | Tab만으로 주요 동작을 수행합니다. |
| [포커스 링 (Focus Ring)](/docs/knowledge/frontend/ui-ux-elements/focus-order) | `Focus Ring & Order` | 포커스 링과 Tab 순서를 확인합니다. |
| [포커스 트랩 (Focus Trap)](/docs/knowledge/frontend/ui-ux-elements/modal-focus-trap) | `Focus Trap` | 모달 포커스 트랩과 닫은 뒤 복귀를 확인합니다. |
| [라이브 리전 (Live Region)](/docs/knowledge/frontend/ui-ux-elements/sr-announcement) | `ARIA Live Region` | aria-label과 aria-live로 상태 안내가 나가는지 확인합니다. |
| [상태 표시 (Non-color Status)](/docs/knowledge/frontend/ui-ux-elements/contrast-status) | `Non-color Status` | 색만으로 구분하지 않고 아이콘+문구로 상태를 표시합니다. |
| [텍스트 확대 (Text Zoom)](/docs/knowledge/frontend/ui-ux-elements/text-zoom) | `Text Zoom` | 글자 크기 옵션으로 레이아웃을 확인합니다. |
| [컬러 모드 (Color Mode)](/docs/knowledge/frontend/ui-ux-elements/color-mode) | `Color Mode / Dark Mode` | 데모 영역만 라이트/다크를 전환합니다. 사이트 전역 테마와 별개입니다. |
| [터치 타깃 (Touch Target)](/docs/knowledge/frontend/ui-ux-elements/touch-target) | `Touch Target` | 권장 최소 터치 영역(약 44px)을 확인합니다. |
| [가로 모드 (Landscape)](/docs/knowledge/frontend/ui-ux-elements/landscape) | `Landscape Layout` | 가로형 프레임에서 배치를 확인합니다. |
| [긴 문구 (Long Copy)](/docs/knowledge/frontend/ui-ux-elements/long-i18n) | `Long Translation / Copy` | 긴 문구에서 줄바꿈/잘림을 확인합니다. |
