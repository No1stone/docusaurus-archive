# URI

> **개요:** URI(Uniform Resource Identifier, 통일 자원 식별자)와 URL, URN을 구분해 둔 메모입니다.

## URI

Uniform Resource Identifier, 통일 자원 식별자입니다.
자원을 가리키는 문자열이며, 그 안에서 위치(locator)와 이름(name)으로 더 나눌 수 있습니다.

## URL

Uniform Resource Locator입니다.
자원의 **위치**를 나타냅니다.

## URN

Uniform Resource Name입니다.
자원의 **이름**을 나타냅니다.
이름으로 실제 리소스를 찾는 방법은 보편화되지 않았다는 메모입니다.
