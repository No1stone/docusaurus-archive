# port

> **개요:** 전송 계층에서 애플리케이션 도착점 역할을 하는 포트 번호 메모입니다.

## 범위

항구(도착점)에 비유합니다.
사용 가능 범위는 0 ~ 65535 입니다.
0 ~ 1023 잘 알려진 포트는 함부로 쓰지 않는 것이 좋습니다.

## 잘 알려진 포트 예

| 서비스 | 포트 |
|---|---|
| FTP | 20, 21 |
| Telnet | 23 |
| HTTP | 80 |
| HTTPS | 443 |
