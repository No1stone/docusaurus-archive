# 로드밸런스 컨트롤만들기

## 개요

로드밸런스 컨트롤만들기입니다.

1. iam 공급자
1. 공급자 확인하기
1. 결과 id 뒤에값으로 수정
5.정책 만들기
1. 로드밸런서 컨트롤 만들기
1. TLS 인증서 오픈소스
1. 로드밸런서 컨트롤 다운로드
1. 야믈파일 클러스터 편집 800라인에있음
1. 서비스어카운트삭제 540라인
1. 로드밸런스 컨트롤러 배포
1. 서비스어카운트 확인

## 예제·코드

```bash
cd ~/environment

mkdir -p manifests/alb-ingress-controller && cd manifests/alb-ingress-controller

# 최종 폴더 위치
/home/ec2-user/environment/manifests/alb-ingress-controller
```

```bash
eksctl utils associate-iam-oidc-provider \
    --region ${AWS_REGION} \
    --cluster hooxiadmin \
    --approve
```

```bash
aws eks describe-cluster --name hooxiadmin --query "cluster.identity.oidc.issuer" --output text
```
