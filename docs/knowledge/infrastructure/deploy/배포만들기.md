# 배포만들기

## 개요

배포만들기입니다.

1. 디플로이 매니패스트 생성
1. 서비스매니패스트 생성

## 예제·코드

```bash
cat <<EOF> hooxiadmin-deployment.yaml
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: hooxiadmin
  namespace: default
spec:
  replicas: 2
  selector:
    matchLabels:
      app: hooxiadmin
  template:
    metadata:
      labels:
        app: hooxiadmin
    spec:
      containers:
        - name: hooxiadmin
          image: $ACCOUNT_ID.dkr.ecr.$AWS_REGION.amazonaws.com/hooxiadmin:latest
          imagePullPolicy: Always
          ports:
            - containerPort: 8080
EOF
```

```bash
cat <<EOF>  hooxiadmin-service.yaml
---
apiVersion: v1
kind: Service
metadata:
  name: hooxiadmin
  annotations:
    alb.ingress.kubernetes.io/healthcheck-path: "/contents/aws"
spec:
  selector:
    app: hooxiadmin
  type: NodePort
  ports:
    - port: 8080 # 서비스가 생성할 포트  
      targetPort: 8080 # 서비스가 접근할 pod의 포트
      protocol: TCP
EOF
```

```bash
cat <<EOF> ingress.yaml
---
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
    name: "admin-ingress"
    namespace: default
    annotations:
      kubernetes.io/ingress.class: alb
      alb.ingress.kubernetes.io/scheme: internet-facing
      alb.ingress.kubernetes.io/target-type: ip
spec:
    rules:
    - http:
        paths:
          - path: /admin
            pathType: Prefix
            backend:
              service:
                name: "hooxiadmin"
                port:
                  number: 8080
EOF
```
