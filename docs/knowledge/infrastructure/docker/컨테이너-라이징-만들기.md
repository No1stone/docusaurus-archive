# 컨테이너 라이징 만들기

## 개요

컨테이너 라이징 만들기입니다.

1.깃 가저오기
1. ecr에 이미지 올리기
1. ecr 레지스트리에 url 부여
이미지를 컨테이너에 푸시하며 aws정보로 docker login을 함
1. 푸시가 됫나 확인하는 법
1. eks 이미지 만들기
1. eks 클러스터 배포

## 예제·코드

```bash
git clone http://git.uinetworks.kr/JangWonSeok/HOOXIADMIN.git
```

```bash
aws ecr create-repository \
--repository-name hooxiadmin \
--image-scanning-configuration scanOnPush=true \
--region ${AWS_REGION}
```

```bash
aws ecr get-login-password --region ${AWS_REGION} | docker login --username AWS --password-stdin $ACCOUNT_ID.dkr.ecr.$AWS_REGION.amazonaws.com
```
