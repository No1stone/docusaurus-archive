# aws Kendra

## 개요

Amazon Kendra와 Elasticsearch 기능 비교 메모입니다.

> 원 노트에서는 Elasticsearch와 대비해 주요 기능을 짧게 정리했습니다.
Elasticsearch가 제공하는 일부 기능은 다음과 같습니다.
- 분산 및 고가용성 검색 엔진
- 다중 유형의 다중 테넌트
- RESTful을 포함한 다양한 API 세트
반면 Amazon Kendra는 다음과 같은 주요 기능을 제공합니다.
- 자연어 및 키워드 지원
- 독해와 FAQ 매칭
