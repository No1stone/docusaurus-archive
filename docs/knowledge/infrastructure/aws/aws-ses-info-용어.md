# Aws SES Info, 용어

## 개요

Aws SES Info, 용어입니다.

Aws Simple Email Service
Ec2 자체에서 메일을 보낼수 있음.
Aws SDK 사용하여 보내면됨
Aws SES API
수신한 이메일은 Aws S3에 저장할수있다.
Aws Lambda 를 사용하여 트리거를 셋팅할수있으며 이기능으로 메일을 보낼수 있다.
Aws S3빼고 모든 AWS리소스는 동일한 리전에 있어야 한다(해당리전에 셋팅 필요)
이메일을 수신을 지원하는 AWS 리전
수신을 지원하지 않는 리전
샌드박스 계정은 하루에 200명에게 메일을 보낼수있음
샌드박스는 초당 1개만 보낼수있음
1개의 메세지를 200명에거보내면 전송 할당량 끝
