# AWS CloudFront Info 용어

## 개요

AWS CloudFront Info 용어입니다.

확장가능하고 세계적으로 분산되어있는 네트워크를
빠른 성능으로 연결되어있어 동적콘텐츠를 보안을 적용하여 지원
Amazon CloudFront는 .html, .css, .js 및 이미지 파일과 같은 정적 및 동적 웹 콘텐츠를 사용자에게
빠르게 배포하는 웹 서비스
네트워크를 이용하여 복잡하게 찾아가는것이아니라
AWS Service 끼리 바로연결시켜주는 개념임
Ex) S3스토리지 File upload → CloudFront S3URL Setting(배포)
- 이싸이클을 한번 한 후 비디오 스트리밍 서비스 테스트 가능
S3Upload → FrontCloud URL생성 백엔드 서버가 필요함.
AWS ORIGIN
**데이터 가져오기를 위한 AWS 클라우드 서비스와 Amazon CloudFront 간 무료 데이터 전송**
Amazon S3, Amazon EC2 또는 Elastic Load Balancing과 같은 AWS 오리진을 사용하는 경우 오리진에서 CloudFront 엣지 로케이션으로 전송되는 데이터에 대한 요금이 부과되지 않습니다. 이러한 유형의 데이터 전송을 오리진 가져오기라고 합니다. 모든 Amazon CloudFront 기능 및 구성 방법에 대한 자세한 내용은
