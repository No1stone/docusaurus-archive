# AWS CloudFront

> **개요:** Amazon CloudFront는 정적, 동적 웹 콘텐츠를 엣지 네트워크로 빠르게 전달하는 CDN 서비스입니다.
> 이 문서는 CloudFront 관련 메모의 진입점입니다.

## 관련 메모

CloudFront 용어와 오리진, 스트리밍 관련 메모는 아래 글을 참고합니다.

- [AWS CloudFront Info 용어](/docs/knowledge/k-aws-cloudfront-info-용어)

원 노트에는 CloudFront 정보, 용어를 따로 정리해 두었습니다.
세부 설명과 스크린샷은 위 문서로 이어집니다.
