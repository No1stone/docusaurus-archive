# Spring Git

## 개요

Spring 공식 GitHub 조직에서 프로젝트 업데이트 내역을 확인하는 진입점입니다.

> 원본 메모의 “업데이트 내역 확인 필수”를 그대로 따릅니다.
는 Spring Boot, Spring Framework, Spring Security 등 공식 저장소가 모인 조직 페이지입니다.
의존하는 모듈의 Issues, Releases, 최근 커밋을 주기적으로 보면 호환성 깨짐이나 보안 수정에 빨리 대응할 수 있습니다.
대표 저장소 예시는 다음과 같습니다.
개별 모듈 문서는 와 각 저장소 README와 wiki를 함께 봅니다.

| 저장소 | 역할 |
|--------|------|
| spring-boot | 애플리케이션 부트스트랩과 자동 구성 |
| spring-framework | 코어 컨테이너, MVC, WebFlux 등 |
| spring-security | 인증과 인가 |
| spring-data-examples | Data 모듈 예제 |
