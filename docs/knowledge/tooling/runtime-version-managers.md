# 런타임, 개발 도구 버전 관리 툴

| 범위 | 도구 | 특징 |
|---|---|---|
| 여러 언어와 도구 | [mise](https://mise.jdx.dev/) | Java, Node 등 버전과 환경변수, 작업 명령 통합 관리 |
| 여러 언어와 도구 | [asdf](https://asdf-vm.com/) | 플러그인 기반의 여러 런타임 버전 관리 |
| JVM 계열 | [SDKMAN!](https://sdkman.io/usage/) | JDK 배포판, Kotlin, Gradle, Maven 등 관리 |
| Node.js | [nvm](https://github.com/nvm-sh/nvm) | 셸 기반 Node 버전 관리, `.nvmrc` 사용 |
| Node.js | [fnm](https://github.com/Schniz/fnm) | Rust로 만든 버전 관리자, `.nvmrc`와 `.node-version` 지원 |
| JavaScript 도구 | [Volta](https://volta.sh/) | Node와 패키지 매니저 등 관리, 프로젝트별 버전 고정 |
| Node.js | [n](https://github.com/tj/n) | 간단한 명령으로 Node 설치와 버전 전환 |
