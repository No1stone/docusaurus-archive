# medium

## 개요

Spring Boot 3와 Spring Security 6에서 JWT 인증과 인가를 다루는 Medium 글 링크입니다.

> 제목 medium은 원본 Notion 페이지명을 그대로 둡니다.
저장된 URL 제목은 JWT Authentication and Authorization with Spring Boot 3 and Spring Security 6입니다.
Boot 3 / Security 6로 넘어가며 바뀐 Security Filter Chain, JWT 발급과 검증 흐름을 볼 때 열어 두었던 글입니다.
상세 코드와 설정은 원문에서 확인합니다.
작성 시점에 해당 Medium URL 본문 조회가 실패했습니다(HTTP 403).
링크는 유지하며, 브라우저 로그인이나 재시도로 원문을 확인합니다.
