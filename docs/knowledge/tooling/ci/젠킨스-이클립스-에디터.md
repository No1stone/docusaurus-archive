## 개요

젠킨스 이클립스 에디터 관련 원문 링크 범위 안내입니다.

-  — Jenkins – an open source automation server which enables developers around the world to reliably build, test, and deploy their software
상세 절차와 최신 옵션은 위 링크의 원문을 확인합니다.
