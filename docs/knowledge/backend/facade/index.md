# Facade

> **개요:** Facade는 기능 책임과 데이터 소유권에 따라 외부 계약과 허용된 접근 경로를 정하는 경계입니다.
> 필요한 기능만 유스케이스로 조합하고, 모든 요청이 여러 Facade를 통과하지는 않습니다.
