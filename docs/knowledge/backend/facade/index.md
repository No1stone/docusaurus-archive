# Facade

> **개요:** Facade는 테이블 입구, 업무 조합, 화면 조합, 도메인 공개 경계 중 필요한 책임을 맡습니다.
> 모든 요청이 여러 Facade를 통과하지는 않습니다.

- [Facade Design](./facade-design.md)

테이블 한 장에 대응하는 코드 모양은 저장소 `docs/harness/templates/backend/spring/facade/` 입니다.
