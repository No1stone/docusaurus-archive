# 알림

사용자에게 사건을 알리는 일과, 그 알림을 다시 읽고 배지를 갱신하는 일은 범위가 다릅니다.<br />
알림함에서 읽음 상태를 관리하고, 열린 클라이언트에는 SSE나 푸시로 변화를 전달합니다.

**하네스 필독이 아닙니다.**

| 지금 겪는 문제 | 읽을 글 |
|---|---|
| 알림 종류와 쓸 기술이 헷갈림 | [알림 설계와 전달 방식](/docs/knowledge/backend/notification/notification-design-and-delivery) |
| 알림함 데이터와 읽음 API를 잡고 싶음 | [알림함과 읽음 상태](/docs/knowledge/backend/notification/inbox-and-read-state) |
| 웹 상단 배지를 실시간으로 갱신하고 싶음 | [SSE로 인앱 알림 배지 갱신](/docs/knowledge/backend/notification/sse-inapp-badge) |
| 앱, 브라우저 푸시 토큰과 구독을 다루고 싶음 | [모바일 앱 푸시와 웹 푸시](/docs/knowledge/backend/notification/mobile-and-web-push) |
