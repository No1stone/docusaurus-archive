# Sun JAVA

## 개요

Oracle이 호스팅하는 Code Conventions for the Java Programming Language(1999-04-20 개정)입니다.
파일 이름, 들여쓰기, 주석, 명명, 프로그래밍 관례의 목차 수준 기준 문서입니다.
현대 팀의 formatter·linter와 세부 규칙은 다를 수 있어, 필요한 절만 참고합니다.

## 문서가 다루는 범위

1. Introduction
2. File Names
3. File Organization (주석, package/import, 클래스 선언 순서)
4. Indentation
5. Comments (구현 주석, Javadoc)
6. Declarations
7. Statements (`if`, `for`, `switch`, `try-catch` 등)
8. White Space
9. Naming Conventions
10. Programming Practices
11. Code Examples
