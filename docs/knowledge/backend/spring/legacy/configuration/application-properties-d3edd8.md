# application properties

## 개요

외부 리소스로 쓰는 프로퍼티 파일 예시입니다.
고객, 시즌, 연말 할인율을 키로 둡니다.

## 예시

```properties
specialcustomer.discount=0.1
summer.discount=0.15
endofyear.discount=0.2
```
