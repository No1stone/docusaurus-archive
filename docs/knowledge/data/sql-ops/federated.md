# FEDERATED

## 개요

FEDERATED 관련 원문 링크 범위 안내입니다.

상세 절차와 최신 옵션은 위 링크의 원문을 확인합니다.
이 글은 링크 보관과 범위 안내만 하며, 특정 환경의 실측 수치를 주장하지 않습니다.
