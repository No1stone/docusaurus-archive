# ip

> **개요:** IP(인터넷 프로토콜)의 비연결성, 비신뢰성과, 패킷에 들어가는 정보를 적어 둔 메모입니다.

## 주소

예: `0.0.0.0` (자리 표시용으로 적힌 값입니다).

## 특성

- **비연결성:** 상대가 없어도 전송을 시도할 수 있습니다.
- **비신뢰성:** 패킷이 사라지거나 순서가 어긋날 수 있습니다.

## 프로그램 구분

서버에 애플리케이션이 여러 개일 때는 IP만으로는 부족하고, 포트 등과 함께 구분합니다.

## 패킷에 실리는 정보 (메모)

- 출발지 IP
- 도착지 IP
- 전송 데이터
