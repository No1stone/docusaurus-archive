# k3d

**k3d**는 **도커(Docker) 위에서 Rancher의 경량 쿠버네티스 배포판인 [K3s](https://www.google.com/search?q=K3s\&oq=k3d+%EB%9E%80\&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIHCAEQABiABDIHCAIQABiABDIHCAMQABiABDIHCAQQABiABDIHCAUQABiABDIHCAYQABiABDIGCAcQRRg90gEIMTU4MmowajeoAgCwAgA\&sourceid=chrome\&ie=UTF-8\&mstk=AUtExfBeIpKgDnDt4jmKvTiOtUHQQjCGaNHCqEro5OTqw0dqUUlS8KWprGY4Qwf51Y9qjuPTG_GHyDVmtU1u8Rbahh3x5XfxiZNjgLcNLjsYbA2V_TV9S4oFv9A4R9iON0Fc6juEGpzmPINU_rX7aGrM1FUDFDcAkUQ-QgIDaQI4o4deI4qU\&csui=3\&ved=2ahUKEwixpdXa592RAxVmn68BHTLfDLUQgK4QegQIARAC) 클러스터를**

**빠르고 쉽게 실행할 수 있도록 만든 도구**로, 로컬 개발, 테스트, CI 환경 구축에 유용하며

VM 없이 단일 또는 다중 노드 클러스터 생성을 지원하는 경량 래퍼(wrapper).

노트북에 vm 으로 리소스를 나누면.. core memore 를 효율적으로 사용하지 못할거같아서

k3d로 생성!
